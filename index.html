☁ クラウド同期（複数端末で進捗を共有）

このサイトにはあらかじめクラウド同期の設定が組み込まれているので、名前とパスワードでログインするだけで自動的に同期されます。特に何もする必要はありません。

もし別のFirebaseプロジェクトに変更したい場合は、以下の欄に別の設定情報（config）を貼り付けて「クラウド同期に接続する」を押してください（この端末だけ、組み込み設定より優先されます）。

（参考：新しくFirebaseプロジェクトを作る場合の手順）
①Firebaseコンソールでプロジェクトを新規作成 　②「Firestore Database」を作成（本番モードでOK） 　③「Authentication」→「Sign-in method」で「匿名」を有効化 　④ Firestoreの「ルール」を以下に変更：
rules_version = '2'; service cloud.firestore { match /databases/{database}/documents { match /{document=**} { allow read, write: if request.auth != null; } } } ⑤ プロジェクト設定→「マイアプリ」→ウェブアプリを追加し、表示されたconfigをそのまま下に貼り付け
注意：この方式は「Firebase設定を知っている人なら誰でも読み書きできる」簡易的な仕組みです。友達内など信頼できる範囲での利用を想定してください。DeepSeekのAPIキーなど機密情報はこの仕組みでは同期されません（各端末に個別保存されます）。

      ① Excelから読み込む（正解入りデータにおすすめ）

      「科目」列がない場合は、AIが問題文から科目を推定して補います（推定なので、後で③の欄で必要に応じて修正してください）。問題文・選択肢・正解はExcelの値をそのまま使うので変わりません。年度を入力すると、問題番号とあわせて「令和7年度 第57問」のように一覧に表示されます。

      ② PDFから読み込む（任意・正解なしデータ用）

      AIがテキストを読み取り、科目・問題文・選択肢をJSON形式に整形して下の欄に追記します。1回の応答には長さの上限があるため、一度に3〜5問程度に絞ると失敗しにくくなります（多すぎると出力が途中で切れてエラーになることがあります）。正解が別紙の場合は空欄（AIに聞く）のまま登録されるので、後で「AI解説」ボタンで確認してください。整形結果は必ず内容を確認してからインポートしてください。

      ③ 一括インポート欄（①・②の結果、または直接貼り付け）

      type は choice（択一式）か essay（記述式）。correct は正解の選択肢番号（0始まり）、不明なら空欄でOK。
